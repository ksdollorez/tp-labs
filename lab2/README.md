# Лабораторная работа № 2. Основы ООП

**Дисциплина:** «Технологии программирования»  
**Язык программирования:** Python

## Цель работы

Применить принципы объектно-ориентированного программирования при разработке классов для пошаговой стратегии.

## Задание

Реализовать иерархию игровых объектов. Лучник должен уметь атаковать и перемещаться, крепость — атаковать, а дом на колёсах — перемещаться.

## Ход работы

1. В файле [`source.py`](source.py) создан базовый класс `GameObject`. Он хранит идентификатор, имя и координаты объекта. Для чтения этих данных используются методы `getId()`, `getName()`, `getX()` и `getY()`.
2. От `GameObject` наследуются `Unit` и `Building`. Класс `Unit` хранит здоровье юнита, определяет, жив ли он, и обрабатывает получение урона. Класс `Building` хранит признак готовности постройки и возвращает его методом `isBuilt()`.
3. Для атаки и перемещения созданы отдельные абстрактные классы `Attacker` и `Moveable`. Лучник `Archer` наследуется от `Unit` и реализует обе возможности. Крепость `Fort` и дом на колёсах `MobileHouse` наследуются от `Building`. Крепость реализует только атаку, а дом — только перемещение.

## Принципы ООП в программе

- **Наследование.** `Unit` и `Building` получают общие данные и методы от `GameObject`. Например, имя крепости можно получить методом `getName()`, хотя в классе `Fort` этот метод не объявлен.
- **Инкапсуляция.** Здоровье хранится во внутреннем атрибуте `_hp`. Другие объекты наносят урон через `receiveDamage()`, а не меняют `_hp` напрямую. Метод отклоняет отрицательный урон и не даёт здоровью опуститься ниже нуля.
- **Абстракция.** `Attacker` задаёт метод `attack()`, а `Moveable` — метод `move()`. Эти классы определяют, что объект должен уметь делать. Конкретное поведение задаётся в классах-наследниках.
- **Полиморфизм.** У `Archer` и `Fort` есть общий метод `attack(target)`, но работают они по-разному. Живой лучник наносит 20 единиц урона, а построенная крепость — 35. При вызове `attack(target)` выполняется реализация конкретного объекта.

## Проверка работы

Для проверки создан файл [`main.py`](main.py). В нём лучник и дом меняют координаты, а лучник и крепость по очереди атакуют юнита со здоровьем 100.

Команда запуска из папки лабораторной работы:

```powershell
py -B main.py
```

Результат запуска:

```text
Координаты лучника: 3 4
Здоровье цели после атаки лучника: 80.0
Здоровье цели после атаки крепости: 45.0
Координаты дома: 5 6
```

## Вывод

Реализована иерархия классов для пошаговой стратегии. Общие данные объектов вынесены в базовый класс, а атака и перемещение описаны отдельно. Запуск `main.py` подтвердил, что объекты меняют координаты и наносят урон в соответствии с заданными правилами.
